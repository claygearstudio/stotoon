시연 영상 준비안 (자료 미확정 / 실제 영상 아님)
0~5초: 스토툰 제목과 서비스 목적.
5~15초: 공개 사용 가능한 원고에서 컷 목록 선택.
15~30초: 실제 편집기에서 인물 레이어 이동·크기 변경·대사 수정.
30~40초: 저장 후 다시 열어 편집 상태 유지 확인.
40~50초: 홈페이지 베타 신청과 완료 화면, 가상 정보만 사용.
50~55초: 베타 참여 안내.
로그인이나 ComfyUI 연결, 전체 원고 자동 작화가 되는 것처럼 연출하지 않는다.
사용자가 확인할 자료: 공개할 원고/그림의 사용 권한, 화면에 노출될 내용, 영상 게시 계정과 최종 링크.
현재는 공개 영상이 없으므로 홈페이지의 영상 준비 중 표시를 유지한다.
