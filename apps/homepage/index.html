CAMERA FIRST

그리기 전에, 같은 장면의 기준부터.

컷마다 인물 크기를 임의로 바꾸기보다 체형·키·자세와 카메라를 먼저 정하고 확인하는 제작 흐름을 개발합니다.

EDITABLE BY DESIGN

배경, 인물, 소품을 각자의 레이어로.

완성 배경과 인물별 투명 이미지, 독립 소품을 각각 제작하는 방식이 목표입니다. 통합 이미지를 잘라낸 결과를 레이어별 생성으로 대신하지 않습니다.

개발 방향 안내입니다. 현재 작업실에서 원고 전체를 새 작화로 자동 완성하거나 3D 검수를 자동 강제하는 기능은 제공하지 않습니다.

GOOD TO KNOW

궁금한 점이 있으신가요?

그림을 처음 그려도 사용할 수 있나요?

원고와 장면을 직접 다듬는 도구를 준비하고 있습니다. 공개 베타의 사용 방법과 참여 일정은 확정 후 안내합니다.

원고를 넣으면 만화가 자동으로 완성되나요?

원고 전체를 새 그림으로 자동 완성하는 서비스는 아직 제공하지 않습니다. 소개된 편집 화면과 개발 중인 생성 기능을 구분해 안내합니다.

지금 이 홈페이지에서 편집할 수 있나요?

이번 공개 페이지는 서비스 소개와 베타 신청을 위한 페이지입니다. 작업실 화면은 기능 소개 예시이며 편집 도구를 공개 운영하는 단계는 아닙니다.

베타 신청 후 자동 회신 메일이 오나요?

신청 완료는 화면에서 안내합니다. 신청자에게 보내는 자동 회신 메일은 제공하지 않습니다. 참여 안내는 운영자가 별도로 전달합니다.

신청 정보를 삭제하려면 어떻게 하나요?

개인정보 처리 안내의 문의 이메일로 삭제를 요청할 수 있습니다. 접수 이메일로 본인 확인 후 3영업일 내 처리합니다.
